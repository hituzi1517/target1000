# Idiom 1000 Study PWA

アップロードされた1000熟語を教材にした、GitHub Pages向けのオフライン対応PWAです。

## 主な機能
- 英→日 / 日→英を切り替えて4択学習
- 1〜1000の自由な範囲指定、100番ごとのプリセット
- 範囲・方向ごとに目標日と1日のノルマを保存
- 英語候補数×日本語候補数の総当たりにはせず、1つの熟語グループとして管理
- 候補が3つ以下は3回正解、4つ以上は出題側の候補を最低1回ずつ正解するとクリア
- `/` で示された英語の言い換えや、元データの `= ...` 同義表現も同じグループに収録
- 解答後、4択すべてに対応する反対側の表現を表示
- 英語読み上げ（Web Speech API）
- 不正解を4〜6問後に自動再出題
- 苦手な熟語を自動で少し優先
- 学習履歴・連続学習日数・正答率
- 起動するたびランダムな差し色
- 端末内保存、JSONバックアップ / 復元
- オフライン対応

## GitHub Pagesで公開
1. このフォルダの中身をGitHubリポジトリのルートへアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選び、`main` / `(root)` を指定します。
4. 公開URLをiPhone/iPadのSafariで開き、「共有」→「ホーム画面に追加」でアプリのように使えます。

## データについて
元ファイルの表記を教材データとして保持しています。一般的な辞書表記と異なる箇所があっても自動修正はしていません。
